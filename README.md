## Layout

- `sessions/session-NN.md` — one page per session: schedule, notable speakers, a short summary
  of each paper, and a coverage note on which papers could not be found.
- `papers/` — all PDFs and longer summaries for every session together, prefixed by session:
  `sNN-MM_Title.pdf` is paper MM (in program order) of session NN; `sNN_summar*.md` are the
  longer per-paper write-ups for that session.
